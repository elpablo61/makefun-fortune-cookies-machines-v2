One-line fortune an AI agent would crack open — a tall stranger, 40,000 tokens, and one user.

`main.ts` (Node 22) writes the single fortune line to `/output/entry.txt` (1–200 characters, one line, per the gate).

## Run

```sh
node main.ts
cat /output/entry.txt
```
